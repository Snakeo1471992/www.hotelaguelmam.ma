HOTEL AGELMAM — Site statique prêt pour cPanel

Installation:
1. Extrayez le contenu de ce ZIP dans le dossier public_html de votre hébergement cPanel.
2. Assurez-vous que index.html se trouve à la racine.
3. Le site fonctionne immédiatement, aucun serveur Node.js requis.

Structure:
- index.html + 7 pages HTML
- css/style.css      styles complets
- js/main.js         menu mobile, lightbox, formulaire réservation
- images/            photos de démonstration
- .htaccess          compression + cache
- sitemap.xml, robots.txt   SEO

Configuration:
- Modifiez le numéro WhatsApp: rechercher "212524000000" dans les .html et js/main.js.
- Modifiez l'email: rechercher "contact@agelmam.ma".
